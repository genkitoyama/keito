# keito ボードの扱い方

keito のボードは `boards/<タイトル>__<id>/board.json` に保存されている。**board.json を直接編集しない**こと。必ず CLI（`npm run keito --` または `npx tsx cli/keito.ts`）を通す。CLI は書き込む前に元の状態を履歴に残し、ほかで更新されていれば書き込まずに止まる。開いている画面にはすぐ反映される。

## 基本の流れ

1. `npm run -s keito -- boards` でボードを探す（id・タイトル・更新日時）。
2. `npm run -s keito -- guide` で YAML の書式を読む（初めてのときは必ず）。
3. `npm run -s keito -- show <ボード>` で今の内容を YAML で取る。
4. YAML を直して `npm run -s keito -- apply <ボード> <ファイル>`（または `-` で標準入力）で反映する。
5. `npm run -s keito -- check <ボード>` で矛盾がないか確かめる（要修正があると終了コード 1）。

`<ボード>` は id、フォルダ名、タイトルの一部のどれでもよい。

## ボードの種類

ボードには種類がある（YAML の `kind:`。`keito boards` の 3 列目）。種類に合わない要素は使わない。

- `system`（システム図・既定）: 機材と配線。線の種別は映像・LAN・USB・音声・電源など。
- `software`（ソフトウェア構成図）: アプリ・サーバー・DB などの部品と通信。線の `type` は http / websocket / osc / mqtt / tcp / udp / ndi / file / data、ポートは `spec`（例 `7000/udp`）、`ip` / `host` は動作ホスト。`lists <ボード> comms` で通信一覧。
- `sequence`: シーケンス図だけ。ソースは keito の短い書き方のほか、Mermaid（`sequenceDiagram`）や PlantUML（`@startuml`）をそのまま書いてよい。
- `free`: 図形とメモだけ。配置図・画面割り・体験フローのような絵もここに図形で描く（専用の種類はない）。
- 新しく作るときは `new <タイトル> --kind <種類> --project <案件名>`。同じ案件のボードは案件名をそろえる。
- 同じ案件のボードをまたいで同じものは `shared: キー` でつながる（機材。値は `sh_` で始まる短い文字列）。キーを持つ要素の名前や型番・IP を変えると、apply 時に同じ案件のほかのボードにも反映される。既存のキーは消したり変えたりしない。新しくつなぐときは相手の `shared` を `keito show` で確かめて同じ値を書く（相手にキーがなければアプリでつなぐほうが確実）。YAML でキーだけ書いてつないだものは、システム図の機材の値ににそろう。
- ソフトウェア構成図の部品は `runsOn: <機材の shared キー>` で動作ホストを指せる（host / ip はその機材に合わせて自動で入る）。

## 直し方のこつ

- `show` で取った YAML を**丸ごと**直して `apply` する。消した要素はボードからも消える。
- 既存の要素の `pos` はそのまま残す。新しく足す要素は `pos` を省略すると空いている所に自動で置かれる。全体を並べ直したいときだけ `apply --relayout`。
- 機材とポートは `devices`、ケーブルは `cables`（`from: 機材ID.ポート名`）。ポートを省略すると空いているポートを使い、足りなければ足す。
- 映像の規格（HDMI / SDI …）や音声のコネクタ（XLR / TRS …）はケーブルの `spec` かポート名に書く。ケーブル ID はそこから付く。
- 電源は `type: power`。給電元（UPS・タップ）は機材の `category: 電源` と `capacity`、機器側は `watts`。
- 単価は機材の `price`（円）。購入ステータスは keito では持たない（Excel 側で管理）。

## 表と書き出し

- `lists <ボード> [equipment|cables|summary|power|network|check] [--csv|--json]`: 表を読む。
- `xlsx <ボード> [-o ファイル]`: Excel に書き出す。`--update 前回.xlsx` で前回のファイルを図の内容に更新する（購入ステータスや Excel で足した列は引き継がれる）。
- PDF・画像は画面のエクスポートから（CLI では出せない）。
- `url <ボード>` で画面の URL を返す。人に確認してもらうときに添える。

## 履歴と戻すとき

- `history <ボード>` で履歴の一覧（1 が最新。★ は名前付き）。
- `restore <ボード> <番号|名前>` でその時点に戻す（戻す前の状態も履歴に残る）。
- `name <ボード> <名前>` で今の状態に名前を付けて残す。提出前など、区切りで頼まれたら付ける。
