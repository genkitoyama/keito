# keito

テクニカルディレクター向けの作図ツール。システム構成図（系統図）・フローチャート・シーケンス図・付箋を1枚のボードで描けます。

```bash
npm install
npm run dev      # http://localhost:5183
npm run build    # dist/ に静的ファイル（base は相対パス）
```

## できること

- **機材・配線図**: 機材ライブラリから機材を置き、ポート同士をドラッグで結線。ケーブル種別（HDMI / SDI / DP / LAN / USB / 音声 / 電源 / 光 / DMX / シリアル / 無線）で色分けされ、ケーブルID（`HDMI-01` など）が自動で振られます。長さ・ラベル・備考は右パネルで編集。
- **フローチャート / 付箋 / エリア枠 / シーケンス図**: 図形の辺の●をドラッグで接続、何もない所に落とすと次の図形を作成。エリア枠に入れた機材は、機材リストの「設置場所」になります。
- **機材リスト・ケーブルリスト・ケーブル集計**: 図から自動生成。CSV 書き出し、表計算ソフトへのコピー、行クリックで図上の要素を選択。
- **テキスト / AI から図生成**: ボード全体を YAML で読み書き（git で差分管理可）。`pos` を省略した要素は自動レイアウト。Anthropic API キーを入れると、指示文から YAML を生成・更新できます（キー無しの場合は「プロンプトをコピー」でチャットに貼る運用）。
- **エクスポート**: PNG（1〜4x、透過可）/ SVG / クリップボードへコピー。**CAD風 系統図**は A3/A4 の図面枠・表題欄・凡例つきで、モノクロ（線種で信号を区別）またはカラー。機材表・ケーブル表のシートも付けて PDF 化できます（印刷ダイアログ経由のベクター PDF）。

## 操作

| 操作 | キー |
| --- | --- |
| 選択 / パン | `V` / `H`、Space+ドラッグ、スクロールで移動、⌘+スクロールでズーム |
| 図形 | `R` 四角 / `E` 端子 / `D` 判断 / `O` 楕円 / `S` 付箋 / `T` テキスト / `F` エリア枠 / `Q` シーケンス図 |
| 機材ライブラリ | `L` |
| 文字編集 | ダブルクリック / Enter / そのまま打ち始める。確定は ⌘Enter または Esc |
| 編集 | ⌘Z / ⇧⌘Z、⌘C / ⌘V / ⌘D、Delete、矢印キー（Shift で 1px） |
| 全体表示 / ファイル保存 | ⇧1 / ⌘S |

日本語入力: IME の変換確定 Enter では編集が終わりません。IME オンのままでもツールのショートカットが効き、図形を選択して打ち始めるとそのまま編集に入ります。

## 構成

```
src/model/     データモデル・配線ルーティング・自動レイアウト・YAML・リスト生成・状態管理（UI 非依存）
src/canvas/    SVG 描画（画面とエクスポートで共通）とキャンバス操作
src/export/    PNG / SVG / CAD風シート
src/ui/        ツールバー・インスペクタ・各パネル
src/platform/  保存先とファイル入出力の境界（Tauri 化のときはここを差し替える）
```

ボードはブラウザの localStorage に自動保存されます。持ち運びは「保存」で `.keito.json`、または YAML。

## 既知の制限

- ケーブルは機材を避けて迂回しません（重なったら機材を動かして調整）。経路の手動調整は未対応。
- 共同編集・クラウド共有は未対応（ローカル専用）。
