# keito

テクニカルディレクター向けの作図ツール。システム構成図（系統図）・フローチャート・シーケンス図・付箋を1枚のボードで描けます。

```bash
npm install
npm run dev      # http://localhost:5183
npm run build    # dist/ に静的ファイル（base は相対パス）
```

## できること

- **機材・配線図**: 機材ライブラリから機材を置き、ポート同士をドラッグで結線。ケーブル種別（HDMI / SDI / DP / LAN / USB / 音声 / 電源 / 光 / DMX / シリアル / 無線）で色分けされ、ケーブルID（`HDMI-01` など）が自動で振られます。長さ・ラベル・備考は右パネルで編集。
- **フローチャート / 付箋 / エリア枠 / シーケンス図**: 図形の辺の●をドラッグで接続、何もない所に落とすと次の図形を作成。エリア枠に入れた機材は、機材リストの「設置場所」になります。
- **ケーブルの仕様・独自の種別**: ケーブルに品名・規格（「光 HDMI AOC」「Cat6A STP」など）、メーカー、型番、リンクを書けます。品名・規格は線のラベルに出て、ケーブルリストと集計にも入ります。HDBaseT や Dante のような信号の種別は、ボードごとに追加できます（色とケーブル ID の頭文字つき）。
- **ケーブル ID とラベル**: ケーブル ID（`USB-01` など）は右パネルで書き換えられ、ラベルに出す・出さないを線ごと、またはボード全体で選べます。ラベルは改行できます（図の上では Shift+Enter、右パネルでは Enter）。
- **自動配線**: 線は機材や図形を避けて引かれます（単純な経路が何かを貫く場合だけ、周りを回る経路を探します。エリア枠とテキストは避けません）。
- **整頓**: 上のバーの「整頓」で、配置はそのままに図を整えます。各機材を、いちばん近い「線が一直線になる高さ」へ上下に動かし（列の並び順は変えません）、エリア枠を中身に合わせ直し、向かい合うポート間の折れ位置を重ならない・交差しない順に並べ直します。動かすと何かに重なる・別のエリアを押してしまう場合は、その機材は動かしません。線のつながっていない付箋・画像・シーケンス図などは、横に並んでいれば上端をそろえ、間隔がほぼ同じなら等間隔にします。何度押しても結果は同じです。⌘Z で戻せます。
- **線の色**: 線を選んで色を変えられます。ケーブルは種別ごと（このボードの HDMI すべて、など）が既定で、「この線だけ」にも切り替え可。ポートの色と CAD 図面の凡例も追従します。
- **線の調整**: ケーブル／コネクタを選択すると、縦・横どの区間にもつまみが出て、ドラッグで経路をずらせます（ポートから出る区間も、真っ直ぐな線も動かせます）。ラベルは線に沿ってドラッグで移動。機材をドラッグするときは、つながっているポート同士の高さがそろう位置に吸い付きます。両端の丸をドラッグすると別のポート・図形へつなぎ替え。「↺」で自動経路に戻ります。
- **電源（UPS・電源タップ）**: 電源ケーブルは線を省略し、両端に接続先だけ（`PWR-01 → メインPC` / `⚡ UPS`）を表示するので、多数の機器を UPS につないでも図が埋まりません。機材の本体にドロップすれば空きポートを自動で使い、足りなければ追加します。機材に消費電力(W)、UPS に給電容量(W)を入れると、UPS の上に「⚡ 5台 · 995 / 1200W」と負荷が出て、超過は赤で警告。「電源系統」表でも一覧できます。線で描きたいときはボード情報のチェック、またはケーブル選択時の「線を省略」で切り替え。
- **機材の色分け・見出し**: 機材ノードは色を付けて手配元や系統を区別できます（凡例は色付きの四角を並べるだけ）。エリア枠も色を変えられます。テキストは 標準／中見出し／大見出し／タイトル、図形と付箋の文字は 小／標準／大／特大、エリア枠のタイトルは 標準／大／特大／タイトル から選べ、いずれも太字を切り替えられます。
- **図形の見た目**: 8 色 × 塗り 4 種（淡い塗り / ベタ塗り / 白地に枠線 / 塗りなし＝透過）、枠の点線。コネクタ・ケーブルも点線にできます。選択時に上に出るツールバーか右パネルで切り替え。
- **画像・SVG の埋め込み**: ツールバーの画像ボタン、キャンバスへのドラッグ＆ドロップ、クリップボードからの貼り付け（画像、または SVG のソースコード）で配置。SVG はベクターのまま、大きな写真は長辺 1600px に縮小して保存されます。角のドラッグで比率を保って拡縮（Shift で自由変形）。
- **改訂履歴**: ボード情報の「版を記録」で、その時点の図を版（A, B, …）として改訂内容つきで残せます。過去の版は開いて見る・その内容で図面を書き出す・今の図をその版に戻す、ができます（100 版まで。古いものから消えます）。CAD 図面の改訂欄には直近 6 件が並びます。
- **マイプリセット**: ボードに置いた機材を、右パネルの「マイプリセットに保存」で機材ライブラリに登録できます（名称・メーカー・型番・ポート構成・消費電力・色・リンクごと）。全ボード共通で、`boards/presets.json` に保存されます。
- **機材ライブラリ**: カテゴリは最初たたまれていて、見出しをクリックすると開閉できます（「開く／しまう」で全カテゴリまとめて。開いたカテゴリは覚えています）。検索中はすべて開きます。
- **型番のリンク**: 機材に製品ページなどの URL を付けられます（右パネルの「型番のリンク」。型番欄に URL を貼り付けても入ります）。図では型番がリンク表示になり、選択時の「型番のページ」で開けます。機材リストと CSV には URL 列が付き、書き出した SVG / PDF でも型番がクリックできるリンクになります。
- **機材リスト・ケーブルリスト・ケーブル集計**: 図から自動生成。CSV 書き出し、表計算ソフトへのコピー、行クリックで図上の要素を選択。
- **テキスト / AI から図生成**: ボード全体を YAML で読み書き（git で差分管理可）。`pos` を省略した要素は自動レイアウト。Anthropic API キーを入れると、指示文から YAML を生成・更新できます（キー無しの場合は「プロンプトをコピー」でチャットに貼る運用）。
- **エクスポート**: PNG（1〜4x、透過可）/ SVG / クリップボードへコピー。
- **CAD風 系統図**: JIS Z 8311 の図面様式に沿った A3/A4 横のシート。とじ代 20mm、輪郭線 0.5mm、中心マーク、格子参照、比較目盛、右下の表題欄（案件名・図面名称・図番・縮尺・承認/検図/設計/製図・日付・版・頁）と改訂欄、凡例つき。線の太さは JIS Z 8312（0.18/0.25/0.35/0.5mm）、文字高さは JIS Z 8313（2.5/3.5/5mm）で、図を縮小しても紙面上の線幅は変わりません。ケーブルは受け側に矢印、交差は跨ぎ線、エリアは一点鎖線。モノクロ（線種で信号を区別）とカラーを選べ、機材表・ケーブル表のシートも付けて横向きの PDF にできます（印刷ダイアログ経由のベクター PDF）。

## 操作

| 操作 | キー |
| --- | --- |
| 選択 / パン | `V` / `H`、Space+ドラッグ、スクロールで移動、⌘+スクロールでズーム |
| 図形 | `R` 四角 / `E` 端子 / `D` 判断 / `O` 楕円 / `C` 雲（コメント） / `S` 付箋 / `T` テキスト / `F` エリア枠 / `Q` シーケンス図 |
| 機材ライブラリ | `L` |
| 文字編集 | ダブルクリック / Enter / そのまま打ち始める。確定は ⌘Enter または Esc。入力に合わせて図形が伸びる |
| 次の図形 | 選択中の図形の辺の●をクリック、または ⌘+矢印。●をドラッグで既存の図形・ポートへ接続 |
| コネクタのラベル | コネクタをダブルクリック |
| 複製しながら移動 / 軸固定 | Alt+ドラッグ / Shift+ドラッグ（近くの図形の端・中心に吸着、⌘ で吸着オフ） |
| 空白をダブルクリック | その場に四角を作って入力開始 |
| 編集 | ⌘Z / ⇧⌘Z、⌘C / ⌘V / ⌘D、Delete、矢印キー（Shift で 1px） |
| 全体表示 / ファイル保存 | ⇧1 / ⌘S |

日本語入力: IME の変換確定 Enter では編集が終わりません。IME オンのままでもツールのショートカットが効き、図形を選択して打ち始めるとそのまま編集に入ります。

## 構成

```
src/model/     データモデル・配線ルーティング・自動レイアウト・YAML・リスト生成・状態管理（UI 非依存）
src/canvas/    SVG 描画（画面とエクスポートで共通）とキャンバス操作
src/export/    PNG / SVG / CAD風シート
src/ui/        ツールバー・インスペクタ・各パネル
src/platform/  保存先とファイル入出力の境界（Tauri 化のときはここを差し替える）
server/        開発サーバーに載せるボード保存 API（boards/ フォルダの読み書き）
```

## 保存場所

`npm run dev`（または `npm run preview`）で動かしている間、ボードは PC 上のフォルダに自動保存されます。

```
boards/
  展示システム系統図__e6rbxg5k/     ← 「タイトル__ID」。タイトルを変えるとフォルダ名も追従
    board.json                      ← ボード本体
    assets/54c93f3f….png            ← 埋め込んだ画像（内容のハッシュ名。同じ画像は 1 つだけ）
    revisions/<ID>.json             ← 記録した版ごとの図
```

- ボードごとに URL があります: `http://localhost:5183/#/b/<ID>`。
- 画像はボードのフォルダにファイルとして置かれ、`board.json` には参照（`asset:…`）だけが入ります。容量の上限はありません。
- 削除したボードは `boards/.trash/` に移るだけなので、戻したいときはフォルダを `boards/` に戻します。
- 保存先を変えるには環境変数 `KEITO_BOARDS=/path/to/dir npm run dev`（案件のリポジトリの中に置けば、図も git で管理できます）。`boards/` はこのリポジトリでは `.gitignore` 済み。
- 「書き出し」は画像込みの単一ファイル（`.keito.json`）を作ります。人に渡すときはこちらか、ボードのフォルダごと。
- サーバー無しで開いた場合（静的ビルド）や URL に `?local` を付けた場合は、従来どおりブラウザの localStorage に保存します（約 5MB まで）。

## 既知の制限

- 共同編集・クラウド共有は未対応（ローカル専用）。
