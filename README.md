# keito

[English](README.en.md) | 日本語

テクニカルディレクター向けの作図ツールです。展示やイベントの **系統図（機材と配線）**、**ソフトウェア構成図**、**シーケンス図** を描けます。配置図やメモを描く **自由ボード** もあります。機材リストやケーブル表は、描いた図から作られます。

![系統図を描いているところ。左に図、右に選んだ機材の情報](docs/images/hero.png)

## 特長

- **線は自動で引かれる**：ポートどうしをドラッグでつなぐと、線は機材をよけて引かれ、ケーブル ID（`HDMI-01` など）が自動で振られます。機材を動かすと、線もその場で引き直されます。
- **整頓ボタンで図が整う**：配置の骨格はそのままに、線がまっすぐになる高さへ機材をそろえ、エリア枠の余白をそろえ、線の交差や曲がりを減らします。⌘Z で戻せます。
- **表は図から作られる**：機材リスト、ケーブルリスト、ケーブル集計、電源系統、ネットワーク、チェックの表を、図から自動で作ります。表で直した内容は図にも反映されます。Excel で書き出せて、前回の Excel を更新すれば、購入ステータスなど Excel 側で書き足した内容は残ります。
- **電源の負荷が見える**：UPS や電源タップの上に、つないだ台数と消費電力の合計が出ます。容量を超えると赤で知らせます。
- **ソフトウェアの通信もまとめられる**：アプリどうしの通信をプロトコルとポート番号つきで描き、通信一覧にまとめます。施設側へのファイアウォール申請の資料にも使えます。
- **シーケンス図はテキストで書ける**：Mermaid や PlantUML の書き方を、そのまま貼っても読めます。
- **案件ごとにまとまる**：同じ案件のボードはタブで並びます。ボードをまたいで同じ機材をつなげておけば、名前や IP を直したときにほかのボードにも反映されます。ソフトウェア構成図の部品は、動作ホストにシステム図の機材を選ぶと、そのホスト名と IP が入ります。
- **履歴から戻せる**：編集の区切りごとに自動で履歴が残ります。提出した版に名前を付けて残しておけば、そこからの変更点を一覧にできます。
- **日本語入力が快適**：IME の変換確定の Enter では編集が終わりません。図形を選んで打ち始めると、そのまま入力できます。
- **データは手元に残る**：ボードは PC のフォルダに JSON で保存されます。YAML でも読み書きできるので、git で差分を管理できます。
- **Claude Code から操作できる**：「この系統図に PC をもう 1 台足して」のように頼めば、Claude Code がコマンドラインからボードを書き換えます。

## 画面

### 機材・ケーブル表

図にある機材とケーブルは、そのまま表になります。行をクリックすると、図の上でその機材が選ばれます。

![系統図の下に開いたケーブルリスト](docs/images/lists.png)

### ソフトウェア構成図

アプリやサーバーを、動いている PC ごとにエリアで囲んで描けます。線には通信の種別とポート番号が出ます。

![PC ごとにエリアで囲んだソフトウェア構成図](docs/images/software.png)

### シーケンス図

右のパネルにテキストで書くと、図になります。

![テキストで書いたシーケンス図](docs/images/sequence.png)

### 書き出し

PDF（A4 / A3 横）、画像（PNG / SVG）、表（Excel / CSV）、データ（画像込みの `.keito.json` と YAML）で書き出せます。PDF には図と表をまとめて入れられます。案件まるごと書き出すと、PDF はボードごとの図と表を 1 冊にまとめ、ほかの形式はボードごとのファイルを ZIP にまとめます。

![PDF の書き出し画面。1 ページ目に図、続けて表](docs/images/export.png)

## はじめかた

### デスクトップアプリ（macOS）

[Releases](https://github.com/genkitoyama/keito/releases/latest) から `keito_<バージョン>_aarch64.dmg` をダウンロードし、開いた中の keito を「アプリケーション」フォルダにドラッグします。Apple Silicon（M1 以降）・macOS 11 以降の Mac で動きます。Developer ID で署名し、Apple の公証を通してあるので、警告なしで開けます。

初めて起動したときに、ボードを保存するフォルダ（`書類/keito` か、選んだフォルダ）を決めます。

コマンドラインと Claude Code から使うとき（下の「コマンドラインと Claude Code」）は、ソースも手元に置きます。

### ソースから動かす

ブラウザ版や Intel の Mac で使うとき、開発するときはこちらです。

#### 必要なもの

- [Node.js](https://nodejs.org/) 22 以降
- デスクトップアプリを作るときだけ [Rust](https://www.rust-lang.org/tools/install)（macOS で確認しています）

#### ブラウザで使う

```bash
git clone https://github.com/genkitoyama/keito.git
cd keito
npm install
npm run dev
```

ターミナルに出る URL（ふつうは http://localhost:5183 。使われていれば別の番号）を開きます。初めて開くと、サンプルの案件（系統図・ソフトウェア構成図・シーケンス図の 3 枚）が作られます。

ボードは `keito/boards/` に保存されます。保存先は環境変数 `KEITO_BOARDS` か、`~/.config/keito/config.json` の `"boards"` で変えられます。

#### デスクトップアプリを動かす・作る

```bash
npm run app          # 開発モードで起動
npm run app:build    # .app と .dmg を作る（src-tauri/target/release/bundle/）
npm run app:release  # 署名と公証まで行う配布用の .dmg を作る（docs/development.md）
```

デスクトップアプリで選ぶボードのフォルダを、コマンドラインやブラウザ版と同じにすれば、同じボードを読み書きできます。

## コマンドラインと Claude Code

画面を開かずに、ボードを読み書きできます。ボードは id、フォルダ名、タイトルの一部のどれかで指定します。

```bash
npm run keito -- boards                     # ボードの一覧
npm run keito -- show 系統図 > board.yaml    # YAML で取り出す
npm run keito -- apply 系統図 board.yaml     # 直した YAML を反映する
npm run keito -- xlsx 系統図 --update 機材ケーブル表.xlsx   # 前回の Excel を更新する
```

`npm run keito` だけで、使えるコマンドの一覧が出ます。書き込む前の状態は履歴に残るので、あとから戻せます。

Claude Code 向けの使い方を `.claude/skills/keito/` に入れてあります。keito のフォルダで Claude Code を開けば、言葉で頼むだけで図を直せます。API キーは要りません。

## 既知の制限

- 共同編集とクラウド共有には対応していません。ボードは手元の PC だけに保存されます。人に渡すときは、書き出した `.keito.json` かボードのフォルダごと渡してください。
- 配布しているデスクトップアプリは macOS（Apple Silicon）用だけです。ほかの環境では、ソースから動かしてください。
